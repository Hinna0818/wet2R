# wet2R

[中文版](README.zh-CN.md) | English

**wet2R** collects standard wet-lab protocols and the scripts and R package used to process and visualize the data they generate. It is intended for lab members who run routine molecular biology experiments and want the analysis steps to be reproducible.

### Protocols

- **[RNA extraction (TRIzol method)](protocols/RNA_extraction.md)**: tissue lysis in TRIzol, chloroform phase separation, isopropanol precipitation, and 75% ethanol washing. The appendix explains the function of each TRIzol component, the role of chloroform, and the difference between rpm and ×g.
- **[Centrifugation](protocols/centrifugation.md)**: rules for choosing rotor speed units (rpm vs. ×g), tube placement, balancing the rotor, pre-run checks, safe operation, and post-run cleanup.
- **[RT-qPCR](protocols/RT-qPCR.md)**: RNA quantification and normalization, gDNA removal, reverse transcription to cDNA, and SYBR Green qPCR setup, with controls and quality checks.
- **[Mouse genotyping](protocols/genotyping.md)**: crude genomic DNA extraction from toe or tail tissue by alkaline lysis, genotyping PCR, and agarose gel electrophoresis.

## qPCR quick start

After installation, run this example using the measured data included in the package:

```r
library(wet2R)

path <- system.file("extdata", "qpcr_hsp12.csv", package = "wet2R", mustWork = TRUE)
result <- prepare_qpcr(path, control = "C-")
tests <- test_qpcr(result)
p <- plot_qpcr(result, gene = "HSP12", tests = tests)
p
```

This calculates 2^-ddCt expression, compares each treatment with `C-` using
Welch t-tests on biological-replicate dCt, and applies Holm correction.
The plot uses different gray shades and adjusted-P significance stars.
`p` is a ggplot object; summaries, technical QC, and test results are available
in `result$summary`, `result$technical_qc`, and `tests`.

The HSP12/PGK1 example has three no-heat conditions: control (`C-`),
phenanthroline (`P-`), and thiolutin (`T-`). Each group has two biological
replicates with three technical replicates each. See [data provenance](inst/extdata/SOURCE.md)
and the [demo script](scripts/qpcr_demo.r). Review technical variation and sample
size before interpreting this pilot experiment.

### Use your own data

Replace `path` with your CSV path, `control` with your control group, and `gene`
with your target gene name. Input can also be a data frame, with one row per
technical replicate and these required columns:

| Column | Meaning |
|---|---|
| `group` | Group name, e.g. `WT`, `KO` |
| `bio_rep` | Biological replicate ID |
| `tech_rep` | Technical replicate ID |
| `target_ct` | Ct value of the target gene |
| `reference_ct` | Ct value of the reference gene |

Input contains one target and one reference assay. Additional sample metadata
must be constant within each `group`/`bio_rep` and are retained in the output.
Each assay must have the same number of recorded technical measurements per
sample. Resolve undetected reactions before analysis.

### Notes on the analysis

- Every group needs at least two biological replicates to calculate a standard deviation.
- Ct values must be finite positive numbers. Check undetected reactions before analysis.
- Validate stable reference expression and comparable, near-doubling amplification efficiencies.
- The bar height is the geometric mean of 2^-ddCt. Error bars back-transform mean ddCt +/- SD(dCt), conditional on the observed control mean. They describe dispersion, not treatment-effect confidence intervals.
- `qc_range_max` optionally flags excessive technical Ct ranges. QC never removes observations. One technical replicate has undefined SD and is flagged for insufficient QC.
- Tests use biological-replicate dCt values. `method` accepts `welch`, `student`, `wilcox`, `paired_t`, and `paired_wilcox`. Choose the method from the experimental design; Student's test assumes equal variances.
- Paired tests require an explicit `pair_by` column with complete, unique matches. Equal replicate numbers or a shared plate alone do not establish biological pairing.
- `alternative` is on the dCt scale: `greater` means group1 has higher dCt and lower expression than group2.
- `p_adjust_method` accepts the methods in `stats::p.adjust.methods`. Holm is the default; BH controls FDR under its assumptions. All comparisons in one call form one correction family. Coordinate cross-gene correction outside this single-target function.
- Results include raw/adjusted P values and descriptive fold changes. T-test intervals are pointwise and unadjusted. Wilcoxon results have no mean-difference confidence interval or degrees of freedom.
- Plot annotations use adjusted P values (`significance_label = "stars"` by default, or `"p_adj"`). Subsetting the test table for display preserves the original correction family.
- The default layout uses a centered gene title, bars in distinct gray shades from dark to light, solid black points, and group labels angled at 45 degrees. Test settings and error-bar definitions are available in the results and help pages.
- Named colors and labels follow group names. Customize `base_size`, `bar_width`, `point_size`, `label_angle`, and `show_legend`, or add ggplot2 layers. Default font is `sans`; unavailable explicitly named fonts cause an error.
- Factorial interactions, batch adjustment, and repeated measures beyond pairs need an appropriate statistical model outside these pairwise tests.

### Package development

```r
install.packages(c("roxygen2", "pkgload", "testthat", "readr"))
pkgload::load_all(".")
testthat::test_local(".")
roxygen2::roxygenise(".")
```

```bash
R CMD build .
R CMD check --no-manual wet2R_0.2.0.tar.gz
```

Examples use `system.file()` and run against an installed package. Tests compare
measured-data calculations with R's statistical functions, and check grouping,
pair matching, correction families, colors, and plot construction. Raw data are
preserved in `data-raw/`; regenerate the example with `Rscript data-raw/prepare-example.R`.
See [NEWS.md](NEWS.md) for API changes in version 0.2.0.
