# wet2R

[中文版](README.zh-CN.md) | English

**wet2R** collects standard wet-lab protocols and the scripts and R package used to process and visualize the data they generate. It is intended for lab members who run routine molecular biology experiments and want the analysis steps to be reproducible.

## Contents

| Path | Description |
|---|---|
| [`protocols/`](protocols/) | Step-by-step bench protocols (see below) |
| [`R/`](R/) | The `wet2R` R package: qPCR analysis and plotting functions |
| [`scripts/`](scripts/) | Runnable analysis scripts, including an end-to-end qPCR demo |
| [`data/`](data/) | Small example data (large raw files should not be committed) |
| [`man/`](man/) | Function documentation generated by roxygen2 |

### Protocols

- **[RNA extraction (TRIzol method)](protocols/RNA_extraction.md)**: tissue lysis in TRIzol, chloroform phase separation, isopropanol precipitation, and 75% ethanol washing. The appendix explains the function of each TRIzol component, the role of chloroform, and the difference between rpm and ×g.
- **[Centrifugation](protocols/centrifugation.md)**: rules for choosing rotor speed units (rpm vs. ×g), tube placement, balancing the rotor, pre-run checks, safe operation, and post-run cleanup.
- **[RT-qPCR](protocols/RT-qPCR.md)**: RNA quantification and normalization, gDNA removal, reverse transcription to cDNA, and SYBR Green qPCR setup, with controls and quality checks.
- **[Mouse genotyping](protocols/genotyping.md)**: crude genomic DNA extraction from toe or tail tissue by alkaline lysis, genotyping PCR, and agarose gel electrophoresis.

## Quick start: qPCR analysis

The package reads a CSV file with one row per technical replicate:

| Column | Meaning |
|---|---|
| `group` | Group name, e.g. `WT`, `KO` |
| `bio_rep` | Biological replicate ID |
| `tech_rep` | Technical replicate ID |
| `target_ct` | Ct value of the target gene |
| `reference_ct` | Ct value of the reference (housekeeping) gene |

Relative expression is calculated with the 2^-ddCt method. Each biological replicate is averaged over its technical replicates, and the control group defines the baseline.

```r
library(wet2R)

result <- prepare_qpcr("data/example_qpcr.csv", control = "WT")
result$summary          # group means, SD, and error ranges
result$technical_qc     # Ct range within each biological replicate

p <- plot_qpcr(result, gene = "Il6", group_labels = c("WT", "KO"))
print(p)

save_qpcr(result, p, output_prefix = "results/Il6")
# writes Il6.png (600 dpi), Il6.svg, and three CSV tables
```

The full workflow, including simulated example data, is in [`scripts/qpcr_demo.r`](scripts/qpcr_demo.r). Run it from the repository root:

```bash
Rscript scripts/qpcr_demo.r
```

### Notes on the analysis

- Every group needs at least two biological replicates to calculate a standard deviation.
- Ct values must be finite positive numbers. Check undetected reactions before analysis.
- The bar height is the geometric mean of 2^-ddCt; error bars are derived from the standard deviation of dCt.
- With four or fewer groups, group names are labeled directly on the x axis. With more groups, a legend is shown.
- The default palette was checked for colorblind accessibility. Pass `colors` to override it.
